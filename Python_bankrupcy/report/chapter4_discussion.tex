\chapter{Discussion and Conclusions}

\section*{Discussions}

The comprehensive evaluation of four distinct modeling approaches reveals clear performance hierarchies and trade-offs between different strategies. The analysis encompasses multiple evaluation metrics including overall accuracy, class-specific performance measures, and discriminative ability through ROC-AUC analysis.

Based on the comprehensive evaluation metrics, the models rank as follows in terms of overall effectiveness:

\begin{enumerate}
    \item \textbf{XGBoost Full Features (XGB\_Full)}: Superior performance across all key metrics
    \item \textbf{Random Forest Full Features (RF\_Full)}: Strong performance with some limitations in minority class detection
    \item \textbf{XGBoost Selected Features (XGB\_Selected)}: Moderate performance with computational efficiency benefits
    \item \textbf{Random Forest Selected Features (RF\_Selected)}: Lowest performance across most metrics
\end{enumerate}

The detailed classification reports reveal important insights into model behavior across different classes:

For Minority Class (Bankruptcy) Detection:
XGB\_Full achieves the highest bankruptcy detection capability with 36\% recall and 89\% precision, representing the best balance between sensitivity and specificity for bankruptcy identification. This performance is particularly valuable in practical applications where accurate bankruptcy detection is prioritized over overall accuracy.

Random Forest models demonstrate poor minority class detection, with RF\_Full achieving only 7\% recall and RF\_Selected achieving merely 1\% recall for bankruptcy cases. This limitation significantly reduces their practical utility for bankruptcy prediction applications.

For Majority Class (Non-Bankruptcy) Performance:
All models achieve excellent non-bankruptcy classification performance, with precision and recall values exceeding 95\%. This consistent performance across models reflects the class imbalance in the dataset and the relative ease of identifying financially stable companies.

\section*{Limitations and Future Research Directions}

The severe class imbalance in the dataset (approximately 95\% non-bankrupt cases) presents ongoing challenges that merit further investigation. Future research should explore advanced sampling techniques, cost-sensitive learning approaches, and threshold optimization strategies to improve minority class detection.

While this study successfully integrated multi-year data, the temporal aspects of bankruptcy prediction warrant deeper investigation. Future research could explore time-series modeling approaches and dynamic feature importance evolution across prediction horizons.

The current analysis relies on a single dataset source. External validation using independent bankruptcy datasets would strengthen confidence in the modeling recommendations and assess generalizability across different economic contexts and time periods.

\section*{Conclusions}

This comprehensive study of ensemble methods for bankruptcy prediction yields several definitive conclusions:

\textbf{Algorithmic Superiority:} XGBoost demonstrates clear superiority over Random Forest for bankruptcy prediction tasks, with substantial improvements in discriminative ability and minority class detection.

\textbf{Feature Completeness Importance:} Comprehensive feature sets significantly outperform reduced feature sets, challenging conventional wisdom about feature selection for tree-based ensemble methods.

\textbf{Performance Trade-offs:} While computational efficiency improvements are achievable through feature selection, the performance costs are prohibitive for applications prioritizing prediction accuracy.

\textbf{Practical Recommendations:} XGBoost with full features represents the optimal approach for bankruptcy prediction, offering the best balance of discriminative ability, class-specific performance, and overall accuracy.

These findings provide clear guidance for practitioners implementing bankruptcy prediction systems and establish a robust foundation for future research in financial distress modeling. The demonstrated effectiveness of XGBoost with comprehensive feature sets offers practical value for financial institutions, investment firms, and regulatory agencies seeking reliable bankruptcy prediction capabilities.
