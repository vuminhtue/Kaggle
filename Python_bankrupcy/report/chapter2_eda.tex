\chapter{Data}

This chapter presents a comprehensive exploratory data analysis of the bankruptcy dataset, encompassing data preprocessing, missing value analysis, feature selection strategies, and correlation assessments. The analysis provides crucial insights into data quality and feature relationships that inform subsequent modeling decisions.

The analysis begins with the integration of five separate ARFF files representing bankruptcy data across different time horizons (1-year through 5-year).
The ARFF stands for Attribute-Relation File Format, which is a simple file format for storing data with attributes and relations.
Each dataset was loaded with appropriate handling of missing values (denoted as '?' in the original files) and merged into a unified dataset containing 43,405 observations across 64 financial features plus temporal and target variables.

The consolidated dataset was structured with 64 financial features (X1 through X64), a binary bankruptcy indicator (0 for non-bankrupt, 1 for bankrupt), and a year variable indicating the prediction horizon. 

This integration enables comprehensive analysis across multiple temporal contexts while maintaining data integrity and consistency.

A systematic analysis of missing values revealed significant data quality challenges requiring careful attention. The missing value distribution analysis identified substantial missingness across multiple features, with varying degrees of data completeness. 
Figure \ref{fig:missing_values} shows the percentage distribution of missing values across financial features.
The missing value assessment revealed that feature X37, representing the ratio of (current assets - inventories) to long-term liabilities, exhibited the highest percentage of missing values at approximately 40\% of all observations. This substantial missingness, combined with the availability of related financial ratio variables, led to the decision to remove X37 from subsequent analyses.

Features X21 and X27 also demonstrated notable missing value percentages but were retained for analysis due to their potential predictive value and the feasibility of reliable imputation. The missing value visualization clearly illustrated the heterogeneous distribution of missingness across features, providing guidance for preprocessing decisions.

To address remaining missing values, K-Nearest Neighbors (KNN) imputation was implemented with k=5 neighbors and uniform weighting. This approach was selected due to its ability to preserve local data structures and relationships while providing robust estimates for missing values based on similar observations.

The KNN imputation process considered the similarity between observations across all available features, ensuring that imputed values reflect the underlying data patterns. The choice of k=5 represents a balance between sufficient neighborhood information and computational efficiency, while uniform weighting ensures equal contribution from all neighbors in the imputation process.

Analysis of bankruptcy rates across different time horizons revealed interesting temporal patterns. The distribution of bankruptcy percentages by year showed varying rates of financial distress, with certain prediction horizons exhibiting higher bankruptcy frequencies. This temporal variation underscores the importance of considering time-dependent factors in bankruptcy prediction modeling.
Figure \ref{fig:bankruptcy_by_year} shows the bankruptcy rate in target variable distributed by years.
The bankruptcy rate analysis demonstrated increasing bankruptcy rate over the years, however, the rate change is not significantly different across different years with values ranging from around 4\% to 7\% per annum.

Comprehensive correlation analysis was conducted to identify relationships between financial features and inform feature selection strategies. The correlation matrix analysis revealed numerous strong positive correlations (R > 0.95) between feature pairs, indicating potential redundancy in the feature set.

The top 20 strongest correlation pairs were identified, with several correlations approaching perfect linear relationships. Notable examples include:
\begin{itemize}
    \item X7 and X14 (R = 1.000)
    \item X4 and X46 (R = 0.999)
    \item X20 and X56 (R = 0.999)
    \item X8 and X17 (R = 0.999)
    \item X19 and X23 (R = 0.999)
\end{itemize}

These strong correlations suggest substantial feature redundancy and support the implementation of feature selection strategies to improve model efficiency and interpretability.

To address feature redundancy systematically, hierarchical clustering was applied to the correlation matrix using average linkage methodology. This approach groups features based on their correlation patterns, enabling the identification of feature clusters representing similar financial concepts.

The clustering analysis demonstrated in Figure \ref{fig:correlation_clustermap} resulted in 8 distinct clusters, with cluster 8 identified as the most populous, containing 17 features. This cluster represents a cohesive group of financial indicators sharing similar correlation patterns and underlying financial relationships.

From the top cluster (Figure \ref{fig:top_cluster_heatmap}), features X51 and X54 were removed due to their high correlation with other cluster members, resulting in a selected feature set of 15 variables. This feature selection strategy maintains representative coverage of financial concepts while reducing redundancy and computational complexity.

To validate the feature selection strategy and assess multicollinearity, Variance Inflation Factor (VIF) analysis was conducted on the selected feature subset. The VIF analysis provides quantitative assessment of multicollinearity, with values below 5 generally indicating acceptable levels of feature independence.

The VIF analysis of the 15 selected features (Table \ref{tab:vif_analysis}) revealed satisfactory results, with all features exhibiting VIF values well below the commonly accepted threshold of 5. The VIF values ranged from 1.000 to 2.694, indicating minimal multicollinearity concerns in the selected feature set.

The comprehensive exploratory data analysis established a solid foundation for subsequent modeling efforts. Key preprocessing achievements include:

\begin{enumerate}
    \item Successful integration of multi-year bankruptcy data into a unified dataset
    \item Systematic identification and handling of missing values through targeted removal and KNN imputation
    \item Implementation of correlation-based feature selection reducing the feature space from 64 to 15 variables
    \item Validation of feature selection through VIF analysis confirming minimal multicollinearity
    \item Comprehensive understanding of bankruptcy distribution patterns across temporal horizons
\end{enumerate}

The resulting preprocessed dataset provides both full feature (63 features after X37 removal) and selected feature (15 features) versions, enabling comparative analysis of model performance across different feature complexity levels. This dual approach facilitates assessment of the trade-offs between model complexity and predictive performance in bankruptcy prediction applications.
