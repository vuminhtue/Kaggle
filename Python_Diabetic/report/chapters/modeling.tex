Logistic regression was selected as the primary modeling approach for this analysis due to its interpretability, statistical robustness, and suitability for classification problems. As a parametric model, logistic regression provides clear insights into the relationship between predictors and the probability of hospital readmission, facilitating clinical interpretation and decision-making.

For this multiclass classification problem with three readmission categories ("NO", ">30", "<30"), we employed a multinomial logistic regression approach. This extension of the binary logistic model allows for the prediction of probabilities across multiple classes.

Prior to model training, the preprocessed dataset was partitioned into training and testing sets using a stratified random sampling approach to maintain the class distribution of the target variable. The data was split with 80\% allocated to the training set and 20\% to the testing set.

To ensure robust model evaluation and mitigate the risk of overfitting, we applied 10-Fold cross-validation for the model training with LogisticRegressionCV in scikit-learn.
Cross-validation provides a more reliable estimate of model performance by evaluating it on multiple subsets of the data, reducing the impact of sampling variability on performance assessment and also to avoid overfitting.
Figure~\ref{fig:cv} shows the optimal regularization strength for each class and this regularization strength was used for the final model.

Once identified the optimal Regularization strength C from LogisticRegressionCV, the logistic regression model was trained using the scikit-learn implementation with lbfgs solver, 1000 maximum iterations, multinomial multi-class strategy and accuracy scoring with all available cpus.

The model was evaluated on both the cross-validation folds and the held-out test set using multiple performance metrics including: Accuracy, F1-score, Confusion Matrix, and Classification Report.

For multinomial logistic regression, the model produces a set of coefficients for each class.
The magnitude and direction of these coefficients indicate the strength and nature of the relationship between each feature and the log-odds of belonging to a particular class (Figure~\ref{fig:feature_importance}).

\begin{figure}[H]
    \centering
    \includegraphics[width=1.0\textwidth]{../figures/important.png}
    \caption{Top features by importance for each readmission category}

The top 5 features for each class are among discharge disposition id code 11, 14, 15, 28 stands for "Expired", "Hospice", "Discharge within this institution", "Discharge to psychiatric facility" respectively.
The Top features found from Logistic Regression are based on the coefficients of the model.
The Logistic Regression model is a linear model and hence the coefficients are directly proportional to the importance of the features, assuming linear relationship between the features and the log-odds of the target variable.
This hence makes the categorical features like discharge disposition stronger predictor.

The above feature analysis indicates that there exists potential non-linear relationship between the features and the target variable.
Therefore, in order to find the right importance of the features, it is recommended to use the Random Forest approach (Figure~\ref{fig:rf_imp}):
The importance features found from Random Forest model are more robust and can capture the non-linear relationship between the features and the target variable. Althought the level of importance are not really strong but it is varying across predictors and provides more reliable results than the Logistic Regression model.
